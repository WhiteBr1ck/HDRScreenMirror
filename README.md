<h1 align="center">HDRScreenMirror</h1>

<p align="center">适用于 Windows 的 HDR 屏幕镜像工具</p>

<p align="center"><strong>简体中文</strong> ｜ <a href="README.en.md">English</a></p>

## 为什么需要 HDRScreenMirror

众所周知，Windows 在开启 HDR 后，是不能开启复制屏幕的，只能扩展使用。比如我想在一台电脑上对比两个显示器的 HDR 显示效果，就会比较麻烦。

HDRScreenMirror 就可以从一块显示器实时捕获桌面，再通过 Direct3D 11 将画面以 FP16 scRGB HDR 复制到目标显示器上。

简单来说，它让你可以实现在 Windows HDR 下，近似于实现复制两块屏幕的功能。

现已支持全套的 HDR 分析工具。

## 功能

1. 实时捕获并镜像 Windows HDR 桌面。
2. 使用 FP16 scRGB HDR 输出，尽可能保留 HDR 亮度和色彩信息。
3. 支持单个输出显示器，也支持输出到同一块 GPU 上的所有其他显示器。
4. 支持无需输出显示器的 HDR 单屏分析模式。
5. 自动保持画面宽高比，比例不一致时添加黑边。
6. 可选择是否在输出显示器上渲染鼠标指针。
7. 可在镜像输出屏或单屏分析捕获屏左上角显示实时状态面板。
8. 提供快捷键。
9. HDR 亮度分析工具。
10. HDR 色域分析工具。
11. 提供跟随输出显示器、固定上限和不限制三种帧率策略。
12. Windows 显示分辨率或显示模式变化后自动重新适配并恢复当前会话。
13. 支持根据 OLED 窗口亮度曲线估算 ABL 后的画面平均、最高与最低亮度。
14. 可将渲染完成的 HDR 镜像画面转换并保存为普通 SDR PNG，同时保留可见的分析面板、亮度标记和输出鼠标。

## 系统要求

1. Windows 10 或 Windows 11，64 位版本。
2. [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)。
3. 支持 Direct3D 11 和 Desktop Duplication 的显卡与驱动。
4. 使用 HDR 多屏镜像时，捕获显示器和输出显示器必须连接在同一块 GPU 上。
5. 使用 HDR 多屏镜像时，输出显示器需要在 Windows 设置中开启 HDR。

## 安装

1. 到 release 里面下载并解压 `win-x64` 压缩包。
2. 确认已经安装 .NET 8 Desktop Runtime。
3. 运行 `HDRScreenMirror.exe`。

软件不需要安装程序，删除解压目录即可移除。

程序设置和 ABL 配置档案保存在 `%LocalAppData%\HDRScreenMirror\settings.json`，移动或替换软件目录不会清除这些设置。

## 使用方法

### HDR 多屏镜像

1. 在 Windows 的“系统 > 屏幕”中，将显示模式设置为“扩展这些显示器”。
2. 在 Windows 设置中为目标显示器开启 HDR。
3. 启动 `HDRScreenMirror.exe`。
4. 在“捕获显示器”中选择需要复制的源屏幕。
5. 在“输出显示器”中选择接收镜像的目标屏幕。
6. 点击“开始 HDR 镜像”。
7. 需要结束时，点击“停止”或使用全局快捷键。

### HDR 单屏分析

单屏分析不创建镜像输出窗口，因此只连接一块显示器也可以查看画面亮度、鼠标区域亮度、ABL 估算、亮度极值标记和实时色域分析面板。

1. 在“模式”中选择“HDR 单屏分析”。
2. 选择需要分析的捕获显示器。
3. 至少启用状态面板、最高与最低亮度标记或实时色域分析面板中的一项。
4. 点击“开始 HDR 分析”。
5. 主界面会隐藏到托盘，分析界面显示在捕获屏上并从 Desktop Duplication 捕获中排除。
6. 使用 `Ctrl + F8` 停止分析，或使用 `Ctrl + F12` 召回主界面。

单屏分析可以覆盖使用普通窗口全屏的应用，但无法覆盖使用独占全屏或独立呈现路径的应用。

### 输出到三块或更多显示器

勾选“输出到所有同显卡显示器”后，程序会忽略单个输出选择，并把捕获画面呈现到捕获屏之外、连接在同一块 GPU 上的全部显示器。

例如三块显示器全部连接到同一块显卡时，可以捕获第一块显示器，并同时输出到第二块和第三块显示器。

## 主要选项

| 选项 | 默认值 | 作用 |
| --- | --- | --- |
| 模式 | HDR 多屏镜像 | 可手动切换 HDR 多屏镜像和 HDR 单屏分析；单屏分析不需要输出显示器 |
| SDR 白点亮度 | 203 nits | 控制 SDR 回退画面和鼠标指针在 HDR 输出中的亮度，不改变 FP16 HDR 主画面 |
| 帧率策略 | 跟随输出显示器 | 可选择跟随输出显示器、固定上限或不限制；固定上限支持 24 至 500 fps |
| 状态面板 | 开启 | 在镜像输出屏或单屏分析捕获屏左上角显示分辨率、格式、帧率、鼠标状态和画面亮度数据 |
| 在输出屏渲染鼠标 | 开启 | 将捕获屏的鼠标指针合成到镜像画面 |
| 显示鼠标指针区域亮度 | 开启 | 在状态面板以三位小数显示鼠标指针所在区域的平均亮度；指针离开捕获屏时显示“不在捕获区域” |
| 输出亮度伪色图 | 关闭 | 将所有输出显示器切换为统一的亮度伪色图，并在状态面板显示色阶图例 |
| 标记画面最高与最低亮度 | 关闭 | 在输出画面上标记平均亮度的最高和最低位置，并显示对应亮度 |
| 显示 ABL 后估算亮度 | 关闭 | 根据当前 OLED 配置档案估算受到 ABL 影响后的画面平均、最高与最低亮度，并显示等效 APL、整体缩放和亮度下降比例 |
| 实时色域分析面板 | 关闭 | 在左下角显示当前画面的 CIE 1976 `u′v′` 热力图、三个参考色域三角形和互斥色域比例 |
| 鼠标穿透输出画面 | 关闭 | 多屏镜像专用；开启后，点击可以穿过镜像窗口到达后面的桌面 |
| 启用全局快捷键 | 开启 | 注册开始或停止、伪色图、截图、状态面板和召回快捷键 |
| 关闭时最小化到托盘 | 关闭 | 点击关闭按钮时隐藏主界面并保持镜像运行 |
| 开始镜像时将输出屏窗口移到捕获屏 | 关闭 | 避免窗口被镜像画面覆盖后无法操作；最小化窗口、系统窗口和管理员权限窗口可能不会移动 |
| 截图保存方式 | 自动保存 | 可选择自动保存，或每次截图时手动选择位置 |
| 截图目录 | 程序目录下的 `Screenshots` | 自动保存时使用，可通过“选择目录”改为其他文件夹 |

### 帧率策略

| 模式 | 作用 |
| --- | --- |
| 跟随输出显示器 | 默认模式。让处理节奏跟随输出显示器，避免在高刷新率捕获屏上进行不必要的高帧率处理 |
| 固定上限 | 将处理帧率限制在设定值，支持 24 至 500 fps |
| 不限制 | 不主动限制处理帧率，适合需要尽可能高捕获速度的场景，但会增加 GPU 占用 |

切换帧率策略需要先停止当前会话。Windows 显示分辨率或显示模式发生变化时，程序会重新扫描显示器、重建会话并自动恢复之前的运行模式。

### 实时色域分析面板

可以显示当前画面元素在各种色域中的占比。

### OLED ABL 亮度估算

点击“管理配置”可保存多台 OLED 的窗口亮度数据。每个档案必须填写 1% 和 100% APL 的峰值亮度，也可以填写 3%、5%、10%、20%、25%、50% 和 75% 节点。未填写的节点按 APL 对数坐标分段线性插值。

启用“显示 ABL 后估算亮度”后，程序先将片源信号亮度裁切到 1% APL 峰值，再通过基础画面平均亮度计算等效 APL，最后按照该 APL 对应峰值与 1% 峰值的比例对整幅画面的亮度进行整体缩放。状态面板会同时显示：

1. ABL 后的画面平均、最高与最低亮度。
2. 当前画面的等效 APL。
3. 当前配置产生的整体缩放比例与亮度下降比例。

配置档案可以新建、复制、重命名、删除和保存。会话运行期间可以直接切换档案或开关 ABL 估算，不需要停止当前会话。所有输出显示器共用当前活动档案。

### 亮度伪色色阶

| 亮度范围 | 连续颜色变化 |
| --- | --- |
| 0 至 100 nits | 黑色连续提升到灰色 |
| 100 至 203 nits | 青色连续过渡到绿色 |
| 203 至 400 nits | 绿色连续过渡到黄色 |
| 400 至 1000 nits | 黄色连续过渡到红色 |
| 1000 至 2000 nits | 红色连续过渡到粉色 |
| 2000 至 4000 nits | 粉色连续过渡到蓝紫色 |
| 4000 nits以上 | 白色 |

## 全局快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + F8` | 开始或停止当前选择的镜像或分析模式 |
| `Ctrl + F9` | 开启或关闭亮度伪色图，仅用于多屏镜像 |
| `Ctrl + F10` | 截取每个输出显示器上的镜像画面，仅用于多屏镜像 |
| `Ctrl + F11` | 显示或隐藏状态面板 |
| `Ctrl + F12` | 将主界面召回捕获显示器 |

## 输出截图

开始多屏镜像后按 `Ctrl + F10`，程序会直接读取每个输出显示器渲染完成的镜像画面。保存成功后，输出显示器会短暂显示提示。截图会包含实际缩放与黑边、输出鼠标、亮度伪色图、可见的状态面板、实时色域分析面板和亮度极值标记。使用多个输出显示器时，每个输出显示器分别保存一张 PNG。单屏分析模式不支持输出画面截图。

“自动保存”会把截图写入设置的目录。默认目录是 `HDRScreenMirror.exe` 同目录下的 `Screenshots` 文件夹。“每次手动选择位置”会在按下快捷键后打开保存对话框。

输出窗口平时会被 Windows 屏幕捕获保护排除，所以系统截图工具可能无法截到它。软件内置截图不依赖系统截图或对输出桌面的二次捕获，而是直接读取软件自身的 FP16 镜像输出，将 HDR 色调映射为 SDR，并以普通 PNG 保存。分析面板和亮度标记会在转换后合成进图片。PNG 适合查看和记录分析结果，但不包含原始 FP16 HDR 数据。

## 系统托盘

开启“关闭时最小化到托盘”后，点击主窗口的关闭按钮只会隐藏主界面，不会停止正在运行的镜像。

双击托盘图标可以重新显示主界面。托盘菜单还可以显示主界面、开始或停止镜像，以及真正退出程序。

## 常见问题

### 无法开始镜像

确认捕获显示器和输出显示器不是同一块屏幕，并且连接在同一块 GPU 上。还应确认目标显示器已经在 Windows 设置中开启 HDR。

### 输出画面亮度或颜色不正确

首先检查输出显示器的 Windows HDR 状态。若捕获驱动只提供 SDR BGRA8 画面，软件只能使用 SDR 回退路径，无法恢复已经被系统色调映射掉的 HDR 高光。

### 视频画面没有被捕获

某些受 DRM 保护的内容以及部分 Windows MPO 硬件覆盖层可能不会稳定进入 Desktop Duplication。这属于 Windows 捕获链路限制。

### 主界面找不到了

按 `Ctrl + F12`。如果启用了托盘模式，也可以双击托盘图标。

### 单屏分析面板被全屏应用遮挡

MPC BE 等使用普通窗口全屏的应用可以自动恢复分析面板层级。使用独占全屏或独立呈现路径的应用无法被普通 Windows 置顶窗口覆盖，例如 HDR + WCG Image Viewer 的全屏模式。请改用窗口化、最大化窗口或无边框全屏模式。

## 已知限制

1. 当前不支持跨 GPU 镜像。
2. HDR 多屏镜像不能将同一块显示器同时作为捕获屏和输出屏；HDR 单屏分析不创建输出窗口。
3. 某些 MPO、受保护视频和独占全屏内容可能无法被 Desktop Duplication 捕获。
4. HDR 单屏分析面板无法覆盖使用独占全屏或独立呈现路径的应用。
